# Ishothat — Ronald Isiko

Personal portfolio for **Ronald Isiko** — Product UI/UX Designer, Creative Marketing Director & Visual Storyteller.
Ntinda, Kampala (Uganda) · working with UK + remote teams.

## What's here

A single, dependency-free `index.html` (embedded CSS + JavaScript) built as a **dark glass-morphism** portfolio:

| Section | What it does |
| --- | --- |
| Sticky glass navbar | `RI` brand mark, `Kampala · UK · Remote` tag, dark/light theme toggle, WhatsApp CTA, mobile sheet menu |
| Hero | Availability status pill, gradient headline, bio, dual CTAs, live "brief console" card with parallax tilt, 4-KPI glass strip with count-up |
| Unicorn Hire | Interactive 4-in-1 role switcher (Product UI/UX · Motion · Photography · Performance Marketing) with keyboard-navigable tabs and per-role detail panels |
| Selected Work | 11 filterable case-study cards with generated SVG artwork + a full case modal (challenge / approach / what shipped) |
| Capabilities | 4-column glass skill panels with animated proficiency bars + certifications |
| Engagements | 4 ways to buy the sprint (audit, product UI sprint, content & motion pack, fractional direction) — each pre-fills the brief form |
| Experience | 2017 → 2026 glass timeline with lens badges that deep-link back into the Unicorn card |
| Sprint Launcher | Brief-builder form that composes a message live and opens it pre-filled in **WhatsApp** or **email** (no backend), plus direct contact coordinates and live Kampala/London clocks |

## Design system

- Palette: `#090d16 → #0f1624` base, teal `#2dd4bf`, amber `#f59e0b`, soft blue `#38bdf8`
- Surfaces: layered translucent fills, `backdrop-filter: blur(16–26px)`, 1px strokes, multi-layer shadows
- Type: Inter (display + body) with JetBrains Mono for labels/data, system-ui fallbacks
- Full light-theme token override (glass morphism preserved), `prefers-reduced-motion` and print styles
- Semantic landmarks, skip link, ARIA tabs/dialog, focus-visible rings, JSON-LD `Person` schema, OG/Twitter meta

## Run locally

```bash
python3 -m http.server 8080 --bind 0.0.0.0
# → http://localhost:8080
```

No build step, no npm install. Open `index.html` directly if you prefer.
